# Unit HSTAR: "the executor took control" (h*) replaces `handoff_occurred` as the handoff indicator

## The defect (verified by Claude)
- `src/sidekick/prefix_source.py:184` sets `handoff_occurred = effective_m < n_source_actions`.
  - `n_source_actions` counts only the source's *executed* CODE/COMPLETE actions (`_n_executed_actions`, :40-51).
  - `effective_m = min(m, n_source_actions)` (:139).
- The loop skips the live phase only when the replayed prefix is *terminal* (`src/sidekick/systems/loop.py:743-756`, `prefix_is_terminal` at :172-180): the last observation is done, or the last action is COMPLETE.
- So when a source planner episode made at most m executed actions and did not end with done/COMPLETE, the flag is false but the executor takes control and acts. Such a source might, for example, repeat REPORT until the 40-step limit.
- A planless key falls in the same class: `n_source_actions` = 0 and an empty prefix, so the executor runs the whole episode with the flag false.
- On dev, cap-81 pooled (171 pairs), this covers 17 of the 100 flag-false episodes at m = 11 and 11 of the 54 at m = 9, on both receivers. It was found by a forensics pass.
- Every handoff-only estimand uses the flag: J10 A1 Amendment 1 §B, J11 L3–L5 companions, J12 D3/D4 (registered, decision-bearing), and the dev ledger rows HO-01..09 and HO-NI-01..03.

## Definition to implement
h* = 1 iff the loop ran live after the replayed prefix, i.e. `skip_live_loop` was false (loop.py:747-749).

It is not recorded directly, so derive it from the prefix-arm episode's own `events.jsonl`, last attempt only (events after the last `run_start`). h* = 1 iff at least one event written by the live loop exists at step ≥ `effective_m` + 1.
- Read the loop's `emit` calls and decide which actor/event types mark a live step: the executor's LLM call, action, parse error, limit or error.
- An episode whose first live step fails to parse, or hits a limit, still has h* = 1.
- Justify the choice with [OBSERVED path:line].
- `effective_m` comes from the handoff `report` event payload.

Keep the existing flag available everywhere, renamed in outputs as `h_flag`.
