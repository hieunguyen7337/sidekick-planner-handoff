## Report keys

This key layout is a contract shared with unit S4-channel, which reads your report. Do not rename.

**Every contrast object carries exactly these keys, plus any extras:**
- `diff_pp`;
- `ci95_pp_scenario`, `ci95_pp_task` (each `[lo, hi]` in pp);
- `p_two_sided` (bootstrap, two-sided, at `threshold_pp`);
- `threshold_pp` (0.0, or −7.0 for NI);
- `n_pairs`;
- `metric` (`goal_pass` | `tgc`).

The top-level keys:

| key | contents |
|---|---|
| `handoff_only.{bplus,zs}.m{6,9,11}` | `n`, `n_handoff`, `n_silenced`, and `mean_all`, `mean_handoff`, `mean_silenced` for `goal_pass` and for `tgc`. `handoff_occurred` is read from the prefix arm; a missing flag counts as silenced and is counted |
| `handoff_only_contrasts.{bplus,zs}.{m6_to_m11,m9_to_m11}.{goal_pass,tgc}` | Three contrast objects: `all`, `handoff_only` and `silenced`. Plus a `decomposition` object with `contribution_handoff`, `contribution_silenced` and `share_handoff`, each with scenario and task CIs; the two contributions sum to `all` |
| `ni.{bplus,zs}.m{9,11}.{goal_pass,tgc}` | Prefix arm minus ceiling at −7 pp: an `all` contrast object and a `handoff_only` contrast object (Σd·h / Σh, whole-scenario resampling), plus the reading `holds` / `fails` on the scenario lower bound |
| `chord.{bplus,zs}.m{9,11}` | `residual_mean_pp`, CIs, `f`, `floor_arm`, `reference_arm`, `n_pairs`. `f` is a plug-in from mean non-cached planner tokens and is not resampled |
| `ganz.{bplus,zs}.m{6,9,11}` | `qrec` = (arm − floor)/(ceiling − floor) on `goal_pass`, and `savings_retained` = (c_ceiling − c_arm)/(c_ceiling − c_floor) on hosted calls and on dollars. Each has a scenario CI, computed as a ratio of means inside each resample |
| `cost_share.{bplus,zs}.m{6,9,11}` | `calls_fraction` (arm hosted calls / ceiling hosted calls) and `dollar_saving_retained`, with CIs |
| `inputs` | Every campaign dir read, with its episode count and crash count |
| `settings` | `n_boot`, `seed` |
