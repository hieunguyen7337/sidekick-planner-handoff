# Draft ledger rows — J16 robustness analyses F-b..F-g (NOT yet in docs/claims_ledger.md)

This is a draft only. None of these rows has been merged into `docs/claims_ledger.md`. The ids start at ROB-10 because the sibling
draft `j16_ledger_rows_inference_draft.md` already uses ROB-01... Every number comes from
`campaign/results/j16_robustness_20260923.report.json` (below: **R**). The generator is
`scripts/analysis/j16_robustness.py`.

The key convention is a jq-style path into R. Pair names that contain spaces or colons are written as literal
bracketed strings, e.g. `F_f_cost_differences.pairs["C1: takeover_k10 - advise_k10_fullctx"]`. Unless a row
says otherwise, intervals are 95% paired cluster-percentile bootstrap intervals with B = 10,000 at seed 20260924, resampling
the 19 scenarios ("scen"). The 57-task clustering ("task") and the legacy seed 20260915 are stored alongside.
The pp values are arm minus comparator. Episodes are paired by (task_id, seed) over j10-clean rows.
